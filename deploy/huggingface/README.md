# BNCC Verifica: API

Verifica se o código da BNCC atribuído a uma questão é o da **habilidade pedida**, e não apenas um código válido. Detecta o **erro invisível**: um código que existe e é do componente e ano certos, mas de outra habilidade.

Documentação interativa em `/docs`.

- Código da ferramenta: [github.com/bncc-lab/api](https://github.com/bncc-lab/api)
- Pesquisa que deu origem (ERI-GO 2026): [github.com/bncc-lab/bncc-lab](https://github.com/bncc-lab/bncc-lab)

Iniciativa independente, sem vínculo com o MEC. Os códigos e textos da BNCC são do Ministério da Educação.
